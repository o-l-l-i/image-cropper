# Image Cropper Tool

A lightweight, browser-based tool to crop images visually and precisely.
You can load an image via file picker or drag & drop, and adjust the crop region using handles or numeric input. All processing is done entirely on your device — nothing is uploaded.

---

**You can use this tool at [https://o-l-l-i.github.io/image-cropper/](https://o-l-l-i.github.io/image-cropper/)**

![Image Cropper Splash](/assets/image_cropper_splash.png)

---

## ✨ Features

- Load images via drag & drop or file input
- Resolutions up to 10k x 10k
- File formats supported: PNG, JPEG, WebP, GIF and AVIF
- Crop using resizable visual box or numeric input
- Aspect ratio lock & live preview
- Runs fully in the browser — no uploads, no servers

---

## Known issues

This tool has been tested primarily in Chrome and Brave (desktop).
It should work reliably in any modern Chromium-based browser, but:
- Drag & Drop may be affected by browser extensions (e.g. privacy or download helpers.)
- If dragging an image doesn't work, try using the "Load Image" button instead.
- Mobile browser support is not currently optimized.
- If something breaks, try disabling conflicting extensions or test in a clean browser profile.
